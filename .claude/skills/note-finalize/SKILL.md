このスキルは、note収益化記事作成パイプラインの最終段階「まとめ(仕上げ)」を担当します。

## 実行手順

1. 引数からテーマを特定し、`articles/YYYY-MM-DD_<テーマ>/draft.md` を読み込む。
2. テーマが資産形成・制度系の内容を含む場合、記事末尾に以下の免責事項を自動挿入する:

```
---
※本記事は情報提供を目的としたものであり、特定の金融商品の売買を推奨するものではありません。投資は必ずご自身の判断と責任において行ってください。
```

3. アフィリエイトリンクを挿入する箇所に、プレースホルダーを入れる:

```
[アフィリエイトリンク挿入: (例)証券会社の口座開設リンクをここに挿入]
```

(実際のリンクはユーザー自身が手動で埋め込む)

3.5. アフィリエイトリンクのプレースホルダーを入れた記事には、景品表示法のステルスマーケティング規制(2023年10月施行)に対応するため、**タイトル直下(リード文の前)**に広告表記を自動挿入する:

```
※本記事にはアフィリエイト広告(PR)を含みます。
```

(記事にアフィリエイトリンクを含まない場合はこの表記は不要)

4. 将来の有料記事化に備え、記事の後半(まとめの手前など)に、コメントアウトの形で有料ラインの候補位置を示す:

```
<!-- 有料化する場合はこの位置に「ここから先は有料」の区切りを入れる候補 -->
```

(現時点では無料公開する前提のため、実際の有料ライン設定は必要になった時にnote上で行う)

5. 全体の見出し・箇条書きなど、noteのエディタに貼り付けやすいシンプルなMarkdown形式に整える。
6. 完成稿を `articles/YYYY-MM-DD_<テーマ>/final.md` として保存する。
7. `articles/_backlog.md` の該当テーマのステータスを「執筆完了(投稿待ち)」に更新する。

## 最後に必ず伝えること

- 完成稿は自動投稿されないこと。note編集画面に手動でコピペし、最終確認の上で自分で投稿する必要があること
- アイキャッチ画像は別途手動で用意する必要があること
- 有料記事化する場合は、勤務先の兼業規定を事前に確認したかどうかを再度確認すること
