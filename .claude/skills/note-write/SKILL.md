このスキルは、note収益化記事作成パイプラインの第3段階「執筆(わかりやすくする)」を担当します。

## 前提

- 想定読者(ペルソナ): 地方公務員(20代後半〜50代)。投資・資産形成については初心者レベル、管理職・キャリアについては同じ立場の実務者
- 専門用語(NISA、iDeCo、インデックスファンド等)は初出時に必ず一言で解説を添える
- 文字数目安: 2,000〜3,000字

## 実行手順

1. 引数からテーマを特定し、`articles/YYYY-MM-DD_<テーマ>/research.md` と `factcheck.md` を読み込む。factcheck.mdで指摘された懸念箇所が未修正であれば、先にそれを踏まえた内容にする(判断がつかない場合はユーザーに確認する)。
2. 以下の標準テンプレートに沿って執筆する:

```
# タイトル(「数字+悩み+ベネフィット」型を基本にする。例:「地方公務員管理職5年目が語る、インデックス投資を始めるべき3つの理由」)

## リード文
読者の悩み・状況に共感する導入(2〜3文)

## 見出し1〜見出し3〜5個
- それぞれ、事実(出典裏付け済み)や体験談を交えて解説する
- 専門用語は都度かみ砕く
- 見出しごとに小まとめを入れてもよい

## まとめ
要点の整理+読者への行動提案(次の一歩)
```

資産形成系テーマの免責事項は `/note-finalize` で自動挿入するため、この段階では書かなくてよい。

3. 完成した下書きを `articles/YYYY-MM-DD_<テーマ>/draft.md` として保存する。

執筆が終わったら、次は `/note-finalize` に進むようユーザーに伝える。
