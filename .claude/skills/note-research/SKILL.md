このスキルは、note収益化記事作成パイプラインの第1段階「情報収集」を担当します。想定読者は「地方公務員(20代後半〜50代)」で、資産形成・キャリアに関心がある層です。

## 実行手順

1. 引数として渡されたテーマ(例:「NISA成長投資枠の始め方」「部下のモチベーション管理で失敗した話」)を確認する。渡されていなければユーザーに質問する。
2. テーマの性質を判定する:
   - **資産形成・制度系**(投資、税制、家計管理など客観的事実が必要なテーマ)
   - **経験談系**(地方公務員としての経験、管理職としての経験)
   - **複合**(両方の要素を含む)
3. フォルダを作成する: `articles/YYYY-MM-DD_<テーマのスラッグ>/`(YYYY-MM-DDは実行日)
4. テーマの性質に応じて情報収集する。

### 資産形成・制度系の場合

以下の一次情報源を優先して検索・参照する(WebSearch/WebFetchを使用):

- 金融庁(https://www.fsa.go.jp/) — NISA・iDeCo制度、資産運用の公式情報
- 国税庁(https://www.nta.go.jp/) — 税制関連
- 日本証券業協会(https://www.jsda.or.jp/)
- 日本銀行(https://www.boj.or.jp/) — 金融政策・統計
- 総務省(https://www.soumu.go.jp/) — 地方公務員制度関連
- 人事院(https://www.jinji.go.jp/) — 公務員の給与・服務関連
- 各証券会社の公式サイト(手数料・制度の一次情報として)

各主張(事実)について、根拠となるURLと確認日を必ず記録する。一次情報源が見つからない場合は、信頼できる複数の二次情報源(大手金融メディア等)でクロスチェックし、その旨を明記する。

### 経験談系の場合

1. まず `articles/experience-library.md` を確認し、テーマに関連する既存のエピソードがないか探す。
2. 使えそうなエピソードがあれば、それを起点にさらに深掘りする質問をユーザーに投げる(例:「そのときの部下の反応はどうでしたか?」)。
3. 関連エピソードがなければ、以下のような質問でインタビューする:
   - 具体的にいつ頃、どんな状況で起きたことか
   - その時どう感じたか、どう対応したか
   - 結果どうなったか、そこから何を学んだか
   - 今の若手公務員/新任管理職に伝えるとしたら何を伝えたいか
4. 聞き出した内容は、**自治体名・部署名・個人名・特定できる事案の詳細を含めず**に一般化してメモする(この段階から匿名化を意識する)。
5. 新しく聞き出したエピソードは `articles/experience-library.md` の適切なカテゴリ(例:部下育成、失敗談、資産形成の実体験、キャリア)に追記する。既存カテゴリに当てはまらなければ新しいカテゴリを追加してよい。

## 出力

- `articles/YYYY-MM-DD_<テーマ>/research.md` に、収集した事実(出典付き)・整理したエピソードをまとめて保存する
- `articles/experience-library.md` を更新した場合はその旨を報告する
- `articles/_backlog.md` に該当テーマの行がなければ追加し、ステータスを「調査中」にする(行があれば更新する)

情報収集が終わったら、次は `/note-factcheck` に進むようユーザーに伝える。
