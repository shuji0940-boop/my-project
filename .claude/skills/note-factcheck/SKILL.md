このスキルは、note収益化記事作成パイプラインの第2段階「ファクトチェック」を担当します。

## 実行手順

1. 引数からテーマを特定し、`articles/YYYY-MM-DD_<テーマ>/research.md` を読み込む(該当フォルダが複数候補あればユーザーに確認する)。
2. 以下の3種類のチェックを行い、`factcheck.md` にまとめる。

### 1. 事実確認(資産形成・制度系の内容がある場合)

- research.md内の各事実について、記録された出典URLが信頼できる一次情報源かを確認する
- 可能であれば、独立した別の情報源でもクロスチェックする(2つ以上のソースで一致することを確認する)
- 制度・数値は最新かどうか確認する(制度改正の可能性がある場合は要注意フラグを立てる)
- 出典が不十分な事実には⚠️を付け、要追加調査として明記する

### 2. 断定的な投資助言表現のチェック

以下のようなNGワード・NG表現パターンがないか、research.mdの内容(将来draft.mdにも適用)をスキャンする:

- 「絶対に儲かる」「必ず増える」「確実に」「ノーリスク」「元本保証」(実際は保証がない商品について)
- 「今すぐ買うべき」「今が最後のチャンス」等の煽り・断定的な行動指示
- 特定の金融商品を名指しで「一番良い」と断定する表現

検出した場合は🚫として箇所を明記し、「客観的な情報提供」に言い換える提案を添える。

### 3. コンプライアンスチェック(公務員・管理職の経験談がある場合)

- 自治体名・部署名・上司や同僚が特定できる固有名詞や詳細な人物描写が含まれていないか確認する
- 懲戒事案や人事の機微情報など、守秘義務に抵触しうる具体的すぎる記述がないか確認する
- 該当箇所があれば🚫として指摘し、一般化・匿名化した言い換え案を提示する
- 記事を有料化(収益化)する場合は、勤務先の兼業(営利目的の兼業)規定を事前に人事担当へ確認するよう、チェックリストに注意書きとして残す(有料記事化のたびに確認を促す)

## 出力形式(factcheck.md)

```
## 事実確認結果
- 確認済み: (事実と出典)
- 要確認: (追加調査が必要な事実)

## NG表現チェック
- 検出箇所と言い換え案(なければ「該当なし」)

## コンプライアンスチェック(公務員・管理職ネタがある場合)
- 検出箇所と匿名化案
- [ ] 有料記事化する場合は兼業規定を人事担当に確認したか
```

`_backlog.md` のステータスは変更しない(「調査中」のまま)。全チェック項目が解消されたら、次は `/note-write` に進むようユーザーに伝える。
